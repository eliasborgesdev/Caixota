# Caixota 0.1.1 — compatibilidade com Caixota Code 1.0.1

Base reconstruída a partir da Caixota 0.1.0. O módulo continua sendo distribuído separadamente.

1. Exporte os códigos importantes como cópia de segurança. Não desinstale a extensão nem o módulo.
2. Extraia este ZIP sobre a mesma pasta que contém o manifest.json da extensão instalada. Aceite substituir os arquivos.
3. Abra chrome://extensions e clique em Recarregar na Caixota. Confira a versão 0.1.1.
4. Na página Módulos, importe o ZIP do Caixota Code 1.0.1 sem extrair. Selecione a categoria Desenvolvimento e os cinco motores junto com o editor.
5. Abra Desenvolvimento. Em C/C++, quando o programa pedir entrada, digite no console inferior e pressione Enter. O botão Parar interrompe inclusive programas aguardando entrada.

As funções de inspeção, detecção, cookies e controle de JavaScript solicitam permissões opcionais e acesso a uma aba selecionada. Alterações de cookies e JavaScript exigem confirmação. A entrada interativa em C/C++ depende do suporte a WebAssembly JSPI do navegador.

## Categoria IA
Abra IA no painel e escolha Verificar, Resumir, Reescrever, Dicionário inteligente, Explicar ou Analisar imagem. Abra Configurações → Ferramentas de IA para cadastrar a sua chave e testar a conexão. A versão 0.1.1 mantém a compatibilidade com o Caixota Code 1.0.1, que continua separado.

A IA precisa de internet. Texto ou imagem só são enviados quando você executa uma ação. No Dicionário e em Explicar, o contexto também pode ser enviado. Verificar consulta as fontes habilitadas. Cada ferramenta de texto pode ser mostrada ou escondida no menu de seleção em Configurações → Ferramentas de IA; atualize as páginas abertas após recarregar a extensão.
